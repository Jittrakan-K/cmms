PTN ORBRAY MAKE MAINTENANCE SIMPLE

แอปพลิเคชันสำหรับอุตสาหกรรม เป็นซอฟต์แวร์สำหรับโรงงานเพื่อซ่อมบำรุงเครื่องจักร (CMMS) หรือ ระบบซ่อมบำรุงออนไลน์ (EMAINTENANCE) ที่สามารถทำงานได้อย่างครอบคลุมสำหรับวิศวกรและช่าง รวมไปถึงผู้เกี่ยวข้อง อีกทั้งมีระบบตรวจสอบสภาพเครื่องจักรที่ช่วยให้วิศวกรสามารถนำข้อมูลที่เกิดขึ้นกับเครื่องจักรในช่วงระหว่างการทำงานมาใช้ประโยชน์ได้อย่างเต็มประสิทธิภาพ และวิเคราะห์ข้อมูลเชิงลึก (DATA ANALYTICS) ช่วยให้ธุรกิจของคุณเดินหน้าได้อย่างไม่มีสะดุด

ใช้กล้องโทรศัพท์หรือแท็บเล็ตสแกน เพื่อเปิดใช้งานและบันทึกงานซ่อมจากทุกอุปกรณ์ ข้อมูลจะซิงค์ตรงกันทั่วโลก
🚀 วิธีสร้าง Firebase ฟรี 100% (Spark Plan):
  1. เปิดเว็บไซต์ console.firebase.google.com ล็อกอินด้วย Gmail
  2. กด "Add project" ตั้งชื่อโปรเจกต์ เช่น orbray-maintenance แล้วกด Create
  3. ที่เมนูซ้ายมือ เลือก Build > Firestore Database > กด Create Database (เลือก Location เช่น Singapore) > เลือกระบบความปลอดภัย "Start in test mode" แล้วกด Enable
  4. กดไอคอนรูปฟันเฟือง ⚙️ (Project settings) > แถบ General เลื่อนลงมาล่างสุดตรง Your apps > กดไอคอนเว็บ </> > ตั้งชื่อแอป > คัดลอกเฉพาะก้อน firebaseConfig = { ... } มาวางในช่องด้านบนนี้
